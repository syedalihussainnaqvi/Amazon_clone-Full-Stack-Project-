Amazon_clone is a full-stack e-commerce web application designed to recreate the experience of a modern online marketplace similar to Amazon. The project is built using React, Vite, and Tailwind CSS for the frontend, while the backend is developed with Node.js and Express.js. MongoDB with Mongoose is used for database management, creating a complete MERN-stack application with a fast, responsive, and user-friendly interface.

The frontend provides a modern multi-page shopping experience using React Router for navigation. Users can browse products, search items, view detailed product pages, add items to the shopping cart, and complete the checkout process. The application also includes user authentication features such as registration, login, forgot password, and protected user dashboards where customers can manage profiles, view order history, and maintain wishlists. Additional pages like About, Contact, FAQ, Privacy Policy, Shipping, Careers, and Gift Cards are included to make the platform look and function like a professional commercial website.

The backend is powered by an Express.js REST API with separate route groups for authentication, products, cart management, orders, and chatbot functionality. MongoDB models are created for users, products, orders, cart items, chat history, and user preferences. The server supports product filtering, sorting, category-based browsing, pagination, and secure authentication using JSON Web Tokens (JWT). Security features such as Helmet middleware, CORS integration, password hashing, validation, and centralized error handling are also implemented.

The project focuses on delivering a complete online shopping experience with responsive design, mobile-friendly layouts, smooth animations using Framer Motion, and a chatbot integrated into the website. It also includes admin-style product management support and database seed scripts for adding initial products. Overall, Amazon_clone demonstrates modern web development practices, scalable architecture, secure backend implementation, and a fully functional e-commerce workflow.
